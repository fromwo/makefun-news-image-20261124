Sum up 24 November's world news in one image: this program draws a 1024×1024 poster of Tuesday 24 November 2026 — Nvidia reinstates Jensen Huang as CEO after pressure from President Trump, with shares jumping 33%; Russia warns Estonia that its border row risks open war with the NATO state; Russian strikes kill at least 14 people in Ukraine's Kyiv region as Zelensky urges the US to release Patriot missiles; 24 people are dead and about 30 still missing after a candy factory fire in Indonesia; Ukraine says its sea drones sank the Russian corvette Merkury off Libya; and UN chief Antonio Guterres calls for a global AI risk-management framework within a year. Written in Node 22 with the standard library only; the PNG, its bitmap font and every icon are drawn by hand in `main.ts`, so each run writes byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
